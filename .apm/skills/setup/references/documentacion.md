# Preparar documentación y conectores

## Raíces locales

Muestra y conserva la lista existente. Permite seleccionar varias raíces absolutas; comprueba cada carpeta y lectura de un archivo representativo sin recorrer fuera del alcance confirmado. Identifica formatos: texto y Markdown pueden leerse nativamente. Para otros formatos verifica un lector local adecuado o MarkItDown con su interfaz disponible y una conversión representativa a texto; cita el original. Consulta documentación real antes de ofrecer instalar dependencias, y comprueba de nuevo tras la acción elegida. Una conversión fallida deja pendiente solo la cobertura afectada.

## Un board remoto

Confirma URL HTTPS y proyecto/board/repositorio exacto. El identificador del sistema es abierto y opcional si URL y conector bastan. Reutiliza primero las herramientas cargadas: descubre sus esquemas, identifica el sitio/organización correspondiente y prueba una consulta de lectura acotada y apertura de un elemento del proyecto, comprobando el mecanismo de paginación. Registra alcance y campos que realmente pueden consultarse. Aplica después las [reglas de corpus y evidencia](../../lee-docs/references/boards.md).

Una página pública puede bastar si la herramienta disponible abre el contenido real; una pantalla de autenticación o un resultado de búsqueda sin documento no demuestran acceso. Sin acceso privado ofrece autenticarse en el anfitrión, reutilizar otro conector adecuado o preparar un conector **existente y documentado**. Lee su configuración y documentación antes de ofrecer registro, transporte, comando o URL; usa las operaciones reales del entorno. Ejecuta el registro solo como acción elegida, preservando otros conectores.

Las credenciales, tokens y flujos de autenticación se gestionan por el anfitrión, fuera del archivo de investigación. Tras registrar o autenticar, repite la consulta de alcance. Si requiere recarga o las herramientas todavía no aparecen, conserva la URL confirmada y marca `PENDIENTE` con recarga/autenticación y consulta posterior concretas.

Raíces locales y board se combinan sin ampliar el corpus. Si el board está pendiente, ofrece avanzar con documentos locales accesibles. La v1 mantiene un board y no añade colecciones remotas independientes.
